# TestFlight 1.2.0 (22)

## 測試內容

本次新增主頁姓名打碼功能，搭配賽博龐克風格亂碼動畫，請協助確認：

1. 首次使用此功能時預設顯示完整姓名。按下姓名旁的淡色眼睛圖示後，上方個人資料列與歡迎區都應改成「姓氏＋同學」，例如「王同學」；再次按下可恢復全名。
2. 隱藏與顯示姓名時，應出現約半秒的藍綠色亂碼與輕微抖動，最後逐字解碼成目標姓名，並正常切換眼睛圖示。
3. 切換顯示方式後，離開並返回主頁或重新開啟 App，確認會保留最後一次選擇。
4. 快速連續按眼睛，或在動畫途中離開主頁再返回，確認姓名不會停在亂碼、變成空白或顯示錯誤狀態。
5. 請留意窄螢幕、長姓名、複姓、淺色／深色模式及放大文字的呈現。開啟「減少動態效果」時應直接切換；使用 VoiceOver 時不應朗讀亂碼，打碼後也不應讀出完整姓名。

若遇到問題，請附上截圖、裝置型號、iOS 版本及重現步驟。
