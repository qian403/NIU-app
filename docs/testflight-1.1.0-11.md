# TestFlight 1.1.0 (11)

## 測試內容

- 首頁功能區最下方新增「郵件包裹查詢」，位於在學證明之後。
- 使用原生 SwiftUI 查詢表單與結果卡片，支援收件人、手機號碼及郵件／包裹號碼條件。
- 可查詢未領取、已領取及退件紀錄，顯示校方收件日期、物流類別、數量與簽收資訊。
- 區分尚未查詢、載入中、查無資料及連線／解析失敗，提供重新查詢與分頁載入。
- 查詢條件變更、離開畫面及切換帳號時取消相關工作，防止舊回應恢復個人資料。
- 使用校方公開查詢入口與暫存連線，不將查詢結果寫入持久化儲存，也不使用固定 SSO GUID。

請確認原生表單、領取狀態切換、包裹結果、更多查詢條件與分頁行為；回報問題時請遮蔽姓名、手機及郵件號碼。

## 驗證與限制

- 郵件查詢離線回歸通過：資料解析、明確空結果、表單編碼、分頁追加與重試、條件變更、取消及過期回應隔離。
- 已用合成收件人實際連線校方 GET／POST 查詢，確認空結果解析成功。
- 模擬器已檢查淺色、深色、放大文字及合成包裹卡片。
- 實際非空郵件紀錄、校方多頁結果及真機操作仍待測試；合成資料測試不等於完成上述驗收。
- Widget 回歸、發行靜態檢查、App／Widget 模擬器編譯及 Release Archive 通過。
