# TestFlight 1.1.0 (10)

## 測試內容

- 首頁新增校園信箱，沿用 App 已儲存的登入資訊，自動登入後開啟校方 Webmail。
- 使用校方介面收發信件、管理草稿與附件，支援子視窗、下載預覽、分享及列印。
- 附件選取沿用 WebKit 系統介面，保留拍照功能；同步說明相機與錄影麥克風的郵件附件用途。
- 切換 App 畫面保留信箱頁面；登出或換帳號會撤銷郵件 session，清理網站資料及下載暫存。
- 移除開發用的獨立 WebKit 範例 App，保留合成資料的登入回歸測試。

請使用自己的測試信件確認收發、草稿、拍照附件、附件下載、分享、列印與換帳號行為。寄出後如遇中斷，先查看寄件備份，避免重複寄出；回報時不要附上帳密、驗證碼、cookie 或完整私人信件。

## 已知限制與驗證

- 驗證圖自動辨識最多三次；連續失敗後目前只能重試，尚未提供人工輸入驗證圖的接續流程。
- 郵件登入離線回歸、生命週期檢查、模擬器目標編譯與發行靜態檢查通過。
- 先前已做授權帳號的唯讀登入與 WebKit 帳號核對，未寄信、刪信或上傳真實附件。
- 真機拍照、附件上傳與真實寄收信全流程尚待測試；編譯與離線測試不代表完成上述驗收。
