# TestFlight 1.0.1 (4) 測試內容

## 繁體中文

本次修正設定頁「M 園區」與「App 後端」連線指示燈可能持續顯示「檢查中」的問題，並加強逾時與取消處理。

請協助測試：

1. 開啟「設定」，確認校務系統、M 園區與 App 後端三個指示燈各自顯示檢查結果，不會一直停在「檢查中」。
2. 在網路不穩、斷線或飛航模式下檢查連線；保持 App 在前景，確認約 12 秒內出現結果，例如「裝置離線」或「連線逾時」。
3. 恢復網路後，點擊指示燈列重新檢查，確認狀態可以更新。
4. 檢查期間連續點擊重新檢查、離開再返回設定頁，或切換背景再回到 App，確認沒有卡住、閃退或舊結果覆蓋新結果。
5. 確認原有登入、課表、成績、M 園區及 Widget 功能仍可正常使用。

提醒：「可連線」只代表服務入口可以存取，不代表校務系統或 M 園區已完成帳號登入。

若遇到問題，請透過 TestFlight 或 App「設定 → 回報問題」提供操作步驟、裝置型號、iOS 版本、網路類型與畫面截圖；請遮蔽個人資料，不要附上密碼、登入憑證或可使用的點名 QR Code。
